# Prepare a Hire review draft
Read the company's candidates and settings first. Ask for missing source records. Use a stable source_id for each business request; do not invent a new key to evade a duplicate refusal. Prepare and read back the record. Report only its actual draft/cancelled state, never external completion. Stop when a request needs authority or a provider action this manifest does not implement.
